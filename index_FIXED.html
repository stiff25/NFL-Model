How the feed works

The GitHub Actions workflow runs the V3 model automatically and writes the latest results to data/current_picks.json. This page reads that file directly.

ML uses model probability versus the no-vig sportsbook probability. ATS uses projected margin versus the current spread. Missing market data is shown as unavailable rather than being treated as zero.

The 62% figure is a target, not a guarantee or a claim that the live model currently achieves it.
